# Event Horizon - Event Management Android Application

## Overview
**Event Horizon** is an intuitive event management Android application developed as a final project for CMPUT 301 - Software Engineering at the University of Alberta. The app allows users to effortlessly create, join, and organize events, streamlining event logistics and improving overall user satisfaction. It leverages modern technologies and design patterns to provide a stable, reliable, and user-friendly experience.

## Features
- **Create Events**: Users can easily create events with all necessary details and invite friends to join.
- **Event Management**: Keep track of upcoming events, manage participants, and organize logistics.
- **Location Integration**: Integrated with Google Maps to display event locations and allow check-ins.
- **User-Friendly Interface**: Designed with Figma for an intuitive and visually appealing user experience.
- **Unit and UI Testing**: Robust testing with JUnit and Espresso ensures high code quality and prevents regressions.

## Technologies Used
- **Java**: Core language for Android development.
- **Firebase**: Backend services for storing user data and event information.
- **Google Maps**: Location services for event check-ins and mapping.
- **JUnit & Espresso**: Tools for unit testing and UI testing.
- **Figma**: Used for designing the user interface and system architecture.
- **GitHub**: Version control and collaboration.

## Software Engineering Design Patterns
Event Horizon implements several software engineering design patterns, including:
- **Model-View-Controller (MVC)**: Separates the application's data, UI, and control logic to improve maintainability and scalability.
- **Adapter Pattern**: Facilitates the integration of different APIs and services, such as Firebase and Google Maps.
- **Singleton Pattern**: Ensures a single instance of the database throughout the application for consistent data management.

## Development Process
This project was developed by a team of 6, following an agile methodology with sprint planning every two weeks. We used UML diagrams and Figma for designing the user interface and system architecture, which improved team collaboration and project clarity. This approach streamlined the development process and ensured seamless feature integration.

## How to Run
1. Clone the repository from GitHub.
2. Open the project in Android Studio.
3. Set up Firebase with your own credentials.
4. Build and run the application on an Android device or emulator.
